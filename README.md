# Ardavan Shamroshan — GitHub Pages

Author landing for open-source packages and plugins at
[ardavanshamroshan.github.io](https://ardavanshamroshan.github.io/).

## Packages linked from this site

- [pydd](https://ardavanshamroshan.github.io/pydd/) — web dump-and-die (`pydd-web`)
- [pydump](https://ardavanshamroshan.github.io/pydump/) — terminal dump-and-die (`pydump-dd`)
- [Filament File Explorer](https://ardavanshamroshan.github.io/filament-file-explorer/) — Filament plugin

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

## Deploy

This repository is the GitHub user site. Push to `main` and enable Pages from the
root of `main`.
